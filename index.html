INTERACTIVE BROKERS · QUICK SETUP

Get your IBKR Flex Query ID & token

These are two different values. The Query ID identifies the report you create; the token authorizes retrieval through the Flex Web Service.

  1. Sign in to IBKR Client Portal. Open Performance & Reports → Flex Queries (menu names may vary).
  2. Under Activity Flex Query, create a new query. Give it a name such as Maximum Dividends and select the dividend, cash transaction and position fields needed by your installed app. Save the query.
  3. Find the saved query's Query ID in the Flex Queries list or its details. Copy the numeric ID.
  4. On the Flex Queries page, open Flex Web Service Configuration. Generate or view your Flex Web Service token and check its expiration date.
  5. Open Maximum Dividends Basic on your Windows computer. In its IBKR/Flex reporting settings, enter the Query ID and token, then use the app's available connection/import control.

Important: Keep your token private. Do not post it in screenshots, support messages or public repositories. A Flex token is not your IBKR login password. If you cannot find a requested field or setting, follow the labels in your installed beta and IBKR's current portal.
